# CritEQ Complete IEM Parametric EQ Preset Database

Database komprehensif profil equalizer parametrik untuk **In-Ear Monitor (IEM) & Earbud** sedunia, bersumber dari **AutoEq**, **Crinacle**, dan seluruh reviewer terkemuka di **Squiglink**.

Total Presets: **5,928 Presets**

### Ringkasan Koleksi & Sumber:
1. **[Crinacle](https://crinacle.com)**: **1,637 presets** (IEC-711 & B&K 4620 high-res measurement couplers).
2. **[Squiglink Reviewers](https://squig.link)**: **2,635 presets** (Super* Review, ToneDeafMonk, Jaytiss, RikudouGoku, Harpo, Fahryst, Kazi, DHRME, kr0mka, freeryder05, Bakkwatan, Ted's Squig Hoard, Auriculares Argentina).
3. **AutoEq & Reference Labs**: **1,656 presets** (oratory1990, Rtings, Innerfidelity, HypetheSonics, Hi End Portable, Headphone.com, Regan Cipher).

### File Gabungan ("All-In-One") Siap Pakai:
- **[`CritEQ - All IEM Presets (Combined).txt`](./CritEQ%20-%20All%20IEM%20Presets%20(Combined).txt)**: Semua 5,928 preset IEM dalam 1 file.
- **[`CritEQ - Crinacle All Presets.txt`](./CritEQ%20-%20Crinacle%20All%20Presets.txt)**: Khusus 1,637 preset dari database Crinacle.
- **[`CritEQ - Squiglink Reviewers All Presets.txt`](./CritEQ%20-%20Squiglink%20Reviewers%20All%20Presets.txt)**: Khusus 2,635 preset dari komunitas reviewer Squiglink.
- **[`CritEQ - AutoEq & Reference All Presets.txt`](./CritEQ%20-%20AutoEq%20%26%20Reference%20All%20Presets.txt)**: Khusus 1,656 preset dari lab oratory1990 & Rtings.
- **[`criteq-all-iem-presets.json`](./criteq-all-iem-presets.json)**: Seluruh database dalam format JSON native CritEQ.

### Cara Menggunakan di CritEQ:
1. Klik tombol **`Import`** di toolbar CritEQ.
2. Pilih file gabungan **`CritEQ - All IEM Presets (Combined).txt`** (atau salah satu file per sumber di atas), atau telusuri folder **`IEM/`** untuk file satuan model favorit Anda.
3. Semua preset langsung muncul di dropdown daftar preset CritEQ dan siap didengarkan!
